Web Wizards 24-Hour Hackathon

About this event

Teams of three build a working website from scratch in 24 hours using HTML, CSS, JavaScript, PHP and Laravel. A problem statement is revealed at the start and mentors from the faculty are available throughout.

Judging covers design quality, working features, code cleanliness and the final demo. Bring your own laptop and charger; snacks and tea are provided overnight.
